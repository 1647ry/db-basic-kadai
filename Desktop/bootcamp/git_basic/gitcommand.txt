Git commandを理解する
clone- リモートリポジトリの内容を自分のローカルマシンにコピーするコマンド

branch- ブランチを新たに作成、一覧表示、削除するコマンド。　複数の開発を管理可能。

checkout- 指定するブランチやコミット内容に作業ディレクトリを切り替えるコマンド。
　　　　　ブランチを新しくもしくは過去の状態に可能。

log- コミットの履歴を時系列で確認できるコマンド。誰がいつ何を変更したのか確認可能。

status- 作業ツリーの状態、インデックスへの登録状況、コミットが必要な変更があるかなど現在のファイル状況を
　　　　一覧表示できるコマンド。

add- ファイルの変更を、コミットするためのインデックスに登録するコマンド。

commit- インデックスに登録された内容をローカルリポジトリの履歴として記録するコマンド。　
　　　　コメントを残すことも可能。

diff- ファイルやリポジトリでどこがどう変わったかを比較、表示するコマンド。

push- ローカルリポジトリのコミットをリモートリポジトリへ反映するコマンド。

pull- リモートリポジトリの最新コミットを取得し、ローカルリポジトリにマージするコマンド。

fetch- リモートリポジトリの最新情報だけを取得し、ローカルリポジトリのリモート追跡ブランチに
　　　反映するコマンド。

merge- 二つのブランチの内容を一つに統合するコマンド。別のブランチで開発した内容を現在の作業ブランチに取り込む。
