github flowとは
Githubが提唱するシンプルで軽量なブランチベースの開発ワークフローである。

特徴
    • メインブランチと作業用ブランチだけを使用
                      →複雑なブランチ構造を避けメインブランチはデプロイ可能(本番環境へ反映可能)な安全状態を保つ

    • 作業用ブランチを切って開発を行う
　　　→新機能や修正はメインブランチからブランチを作成し、そこで作業する。

    • 進行中でもレビュー依頼をする
　　　→早い段階でレビューを受けて改善しながら開発を進める

つまりmainブランチは常に動作する安定版を維持しつつ、細かい単位で作業用ブランチを作成して、プルリクエストでレビューしながらすばやく本番に反映する
