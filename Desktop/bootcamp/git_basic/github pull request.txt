github pull request 
自分の行ったコードの変更を、他の人にレビューしてもらいメインブランチに取り込んでほしいと依頼する仕組み。

特徴
    • プルリクエストを通じて他の開発者から内容のレビューを受けられる。
    • レビューで承認後管理者やレビュワーが変更内容をメインブランチにマージできる。
流れ
    • 作業ブランチの作成
    • 変更or追加のコミット
    • githubにプッシュ
    • プルリクエストを作成し、レビュー依頼
    • 承認後にマージされる
目的
    • 自分の変更、修正が妥当かどうか事前にレビューしてもらう
    • 第三者の確認によりバグなどを防ぐ事ができる
    • コミュニケーションの場を提供できコードの意図や設計方針などをやりとりできる
